# Brushed Metal Creator

Welcome to my sideproject. The original plan was simple - create a dark, brushed steel background that I could use as a background in another project. I got a bit carried away adding extra features.

## Features

<img src="assets/Screenshot_20260828_165953_Brushed Metal Creator.jpg"
	align="right"
    width="150"
    style="margin-left:20px; margin-bottom:20px;" />

- **Procedural Engine**: Generate infinite variations of brushed metal textures without using external assets.
- **Real-time Customisation**: Adjust parameters and see the results instantly.
  - **Grain Intensity**: Control the roughness and visibility of the brushed texture.
  - **Highlights & Shadows**: Fine-tune how light interacts with the metal surface.
  - **Falloff Curve**: Customise the transition between light and dark areas.
- **Rich Colour Palettes**: Choose from a curated list of authentic metal finishes:
  - Stainless Steel, Titanium, Brass, Bronze, Copper, Gunmetal, Obsidian, and more.
- **Gradient Support**: Toggle between Linear and Radial gradients to add depth and dimension to your textures.
- **Export Capabilities**: Save your creations as high-resolution images for use in your own projects.
- **Modern UI**: A clean, gesture-driven interface designed for a seamless creative flow.

## Tech Stack

- **Kotlin**: 100% Kotlin-based project.
- **Jetpack Compose**: Modern declarative UI framework.
- **Coroutines**: Efficient background processing for texture generation.
- **Custom Procedural Engine**: A bespoke noise-based engine for generating realistic metal patterns.
- **Material 3**: Adheres to the latest Material Design guidelines for a consistent look and feel.

## Getting Started

### Prerequisites

- Android Studio Ladybug or newer.
- Android SDK 26+ (Android 8.0).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/macsonprojects/BrushedMetalCreator.git
   ```
2. Open the project in Android Studio.
3. Build and run the app on an emulator or physical device.
